Welcome to Your Website

A simple, no-coding-required guide to owning and updating wildharemoon.com.

Chris built this site using your Wild Hare Moon branding — the hare, the moon, the colors from your card. This guide walks you through making it truly yours: your own free account, your own copy of the code, and, whenever you're ready, the tools to update it yourself. Part One takes about ten minutes. Part Two you can come back to anytime — there's no rush.

Part One

Take Ownership

Five steps, done once. By the end, the website belongs to your own account, and you'll have a live link you can share.

  1. 1

    Create your free GitHub account

    GitHub is where the website's files live — think of it as the filing cabinet for your site, plus the service that shows it to the world for free.

    • Go to github.com/signup
    • Use whichever email you check most — wildharemoon@gmail.com is a good choice
    • Pick a username. Something like wildharemoon works well, but it doesn't need to match your business name
    • Verify your email when GitHub sends the confirmation
    One and done. You'll only ever need to do this step once.
  2. 2

    Create a new repository — your site's project folder

    • Click the + in the top-right corner → New repository
    • Name it wild-hare-moon-website
    • Leave it set to Public — required for free hosting, and it only exposes the website's files, never anything personal
    • Leave every checkbox unchecked (no README, no .gitignore) — Chris will fill it with the current site
    • Click Create repository
  3. 3

    Give Chris temporary access to move the site in

    • On your new repository, go to Settings → Collaborators
    • Click Add people and enter Chris's GitHub username
    • He'll get an invite by email — once he accepts, he can move the current version of the site into your account
    This access isn't permanent — you can remove it from that same screen at any point.
  4. 4

    Let Chris finish the technical setup

    This part he handles from his end — moving the code in and turning on automatic publishing, so any future change goes live within about a minute. Nothing for you to do here except let him know once Steps 1–3 are done.

  5. 5

    Find your live website link

    • Once Chris confirms it's set up, go to Settings → Pages in your repository
    • Your live address is listed at the top — something like https://wildharemoon.github.io/wild-hare-moon-website/

    Safe to share right away. Bookmark it, send it, put it anywhere — it updates automatically from here on.

    About wildharemoon.com: your permanent domain can point to this same site later — a separate, optional step covered in Part Three.

Part Two

Making Updates Yourself

Whenever you're ready — not today, not this month, whenever. Everything below happens in your browser. Nothing to install.

  1. 1

    Editing text

    • In your repository, open site → index.html
    • Click the pencil icon at the top right of the file view to start editing
    • Use Cmd+F (or Ctrl+F) to search the page for the words you want to change — e.g. search “Candle Craft Basics” to jump straight to that class description
    • Type your change directly over the old words
    Stick to plain words. Only edit text sitting in plain view between the angle brackets — like >Your text here<. Anything written in slashes, dots, or all-lowercase-with-dashes is formatting code; leave that alone. When in doubt, message Chris rather than guess.

    Scroll down, add a short note about what you changed (e.g. “updated candle class description”), then click Commit changes. Your live site updates automatically within about a minute.

  2. 2

    Replacing a photo

    • Go to site → assets → img
    • Click Add file → Upload files
    • Drag your new photo in. To have it replace an existing image automatically, name your file exactly the same as the one it's replacing — check the existing filenames in that folder first
    • Adding a brand-new photo instead? Message Chris — the page needs one line added to tell it where the new photo goes

    Commit your change the same way as with text.

  3. 3

    Checking your work

    Open your live link from Settings → Pages and refresh after about a minute.

    You cannot break this. Every change is saved as its own version, forever, so any mistake is one click away from being undone — by you, or by Chris.

Part Three — Optional, For Later

Connecting wildharemoon.com

Right now your site lives at a free github.io address, which works perfectly and can be shared immediately. Whenever you're ready to have it answer to wildharemoon.com instead, that requires access to wherever the domain was originally purchased (the registrar). It's a short, one-time step best done together with Chris, since it touches settings that could affect your email if wildharemoon.com is used for anything else. No rush on this one.
